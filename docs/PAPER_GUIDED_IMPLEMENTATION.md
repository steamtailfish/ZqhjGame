## 在线数据流

```text
obs.self + obs.briefing.score_view.sim_time
  → 单/多检测归一化 → 本机短轨迹 → 本机候选广播
obs.comm_inbox
  → 解码/去重/TTL → 队友状态与候选
  → 确定性候选仲裁 → SEARCH / ACQUIRE / OBSERVE
  → APF引导方向 → 固定翼基元筛选
  → set_heading / set_speed / point_gimbal / set_gimbal_fov
```

所有在线可变状态属于单个Agent实例。在线模块仅依赖Python标准库和公开SDK，不访问文件、Redis、网络、其他Agent对象、场景/路线或裁判真值。工程入口统一PYTHONPATH；在线模块不修改导入路径。

### 观测与通信

- 使用本局公开相对仿真秒；不累加runner的固定dt。缺时间和重复时间不新增控制/消息；倒退时清空实例状态并跳过当前帧。
- `TrackBank`以250m门限做一对一关联，alpha-beta滤波限制估计速度≤25m/s；3次命中且跨≥0.5秒才发候选，2秒内可用，3秒删除。临时编号只在发布者本机有意义。
- 轨迹的不确定性为40–200m的工程启发值，不是经标定的协方差。多车靠近、交叉或噪声超过门限时仍可能换号；不声称稳定识别。
- 广播为版本1的32字节大端结构，经Base85和前缀编码后固定**41字节ASCII**。包含序号、发送仿真时间、本机经纬度/航向/速度、本机轨迹编号/位置/年龄/命中次数/误差尺度。经纬度量化为1e-6度，时间为0.1秒。
- 总发送频率2Hz；仅发一类广播包，不叠加定向消息。自消息丢弃，按发送者/时间/序号去重并处理乱序及序号回绕；队友状态3秒过期。
- 转发的是自己真正观测到的候选，不把队友预测重新包装为新观测。目标年龄保留在包中，旧收件箱不能不断刷新候选。
- SDK没有局号，因此协议不能跨不同赛局混用收件箱；正常runner需按赛局重建/清空通信。它不是可抵抗恶意队友伪造的认证协议。

### 协同与控制

当前只做最多45秒的候选观察尝试，到期冷却30秒后允许再尝试；超时不解释为目标已清除。没有从总清除数、运动或停车推断当前目标身份。广播丢失期间各机可能暂时对角色理解不一致，本版没有确认握手，真实K=2效果尚待验收。

规划器以15–40m/s、5m/s²、30度/s作为运动模型约束。候选路径检查已通信队友、公开任务矩形、公开`no_fly`区域的保守外接圆。队友间隔采用220m加陈旧状态和预测不确定性余量；矩形内留100m余量。区域字段为空不等于感知到环境没有障碍，不能据此宣称未知障碍避让通过。当前赛题二briefing没有障碍几何，未从隐藏地形构造地图。

无可行基元时返回最大化最差间隔的限幅控制，同时记录`plan_feasible=false`；固定翼不能悬停，因此这不是安全保证。采样运动模型、通信时延与真实引擎响应之间仍需验证。任务矩形与本地裁判地图边界的已知差异沿用环境审计。

云台瞄准暂按机头相对pan和地面高程0的条件模型计算，保持50度FOV。该模型仅用于控制试验，不能证明视觉定位标定通过，也没有改动原`project_candidate`的采集位姿拒绝机制。

### 感知和上报

`EntryAgent`采用当前SDK交付的检测坐标作为未核实候选。在现有工程启动命令中它们来自train模拟感知，不是我们的图像识别结果。`VisualEntryAgent.sensor`显式返回空检测，用于需要禁止默认检测器回退的加载场景；它不是已完成的视觉检测器。

`Reporter`实现唯一发布者和1Hz的本地门限，但必须有额外的正向识别与新鲜度证据才允许返回坐标。当前入口没有这类证据，**不调用report_target**。不能把运动或SDK confidence当作真车概率。更复杂的跨候选合并/上报交接、真假识别和每目标覆盖属于后续工作。

## 运行

在SIM_ROOT执行：

```powershell
.\ZqhjGame\run.cmd test
.\ZqhjGame\run.cmd check
.\ZqhjGame\run.cmd dry-run --agent zqhj_entry:EntryAgent --redis-port 6395
.\ZqhjGame\run.cmd agent --agent zqhj_entry:EntryAgent --duration 8 --redis-port 6395
```

`test`不启动Redis或引擎；所有运行记录到`artifacts/`。真实入口仍使用官方train模式，不启动UE。每次保存自研源码SHA256；任何一次运行都不能默认视为视觉eval或600秒完整成绩。

## 尚未实现的论文部分

Gou的rMAPPO、GERD训练奖励、JSRL切换调节器和课程学习，YOPO的深度编码器、终态偏移/打分头及数值梯度反传，均未实现。按此前计划暂不训练，本版先提供可执行、可解释、可验证的解析基线。后续若进入学习阶段，需要单独定义合法训练环境、观测和数据集，并保留本版作对照，不以未训练网络替换当前控制器。

下一步是用真实图像候选/采集姿态对齐接通视觉，再按原计划验证双机共同观察。最终单模块导出、≥2000字技术报告与完整回归仍属于阶段7，本版多模块开发产物不冒称正式提交包。
