# RGB 感知接入记录（2026-09-10）

用户要求在 ZqhjGame 内继续并自行安排路径。本轮已实现可运行的三机 RGB 候选推理、已有 YOPO 引导控制器接入、候选审核与视觉训练入口。**没有完成真车/诱饵分类、在线地理定位、目标上报或真实 K=2 成绩验收。** 主命令为 `VISION_TRAINING_AND_INFERENCE.md`；控制训练命令仍为 `TRAINING_AND_INFERENCE.md`。

## 实现与方法边界

`src/zqhj_vision.py` 使用已加载的私有 Torch 网络，内存解码本机 JPEG，固定方形 LetterBox、RGB/CHW/归一化、原始网络前向、NMS、还原原图连续 xyxy 框。默认1024与发行模型训练尺寸一致；连续框边界可到W/H，像素中心不能据此简单套用整数边界。10张真实图片与 Ultralytics 原预测器复核，包括非空候选，最大数值误差0。

`src/zqhj_photo_entry.py` 在实例内维护最近图像哈希、仿真接收时间、像素匹配和计数。控制/检测都按公开仿真秒限频，wall time只记录推理性能。新图至少相隔0.5仿真秒，两张连续匹配后可进行最多3度的图像中心反馈；超过1秒无新图不再用旧框指挥云台。重复帧、时间倒退、坏图片、检测器异常均有明确处理。

`EntryAgent` 新增候选和云台动作钩子，原 SDK 控制模式保持原行为；`PhotoEntryAgent` 的候选钩子始终不接收 SDK 地理检测，sensor异常也显式返回[]。几何投影的原严格门限没有削弱：采集姿态、FOV轴、地面高程没有证据时不产生经纬度。单类检测置信分数也不用于真车身份判定。

`tools/vision_runner.py` 是离线官方调用器，为每机初始化一个私有视觉模型，并借用现有单文件控制模块的网络构造方法。注册表仅在回合结束后导出各实例自己的记录；Agent没有注册表或其他Agent引用。视觉回调不调用 Ultralytics 高层预测器，避免其目录创建和延迟依赖加载。真实调用为eval+photo on+自定义sensor，不启动默认首机绑定的YOLO worker。

这里的 YOLOv8 是视觉检测器，YOPO 式引导学习是已有控制网络的训练方法；两者通过Agent组合，没有宣称移植YOPO原论文完整视觉规划网络。

## 权重与数据

- 原始官方文件 `examples/yolotrack/target_vehicle_yolov8s.pt` 保持只读，副本在 `artifacts/vision/weights/base_vehicle.pt`。SHA256 `b907ba4368af75411ec802d43607e58ccb85cf4075fe580b6c7a2045015ea31c`。
- 权重实际为 Ultralytics 8.4.77 单类 `TargetVehicle`，训练尺寸1024，参数和原始前向检查未见非有限值。检查点自带训练指标没有在本项目数据上复现，不能直接引用为本项目精度。
- 历史450张公开图像，640/0.15无候选，1024/0.15只有两个候选框。两张原图已查看，边缘/地表区域缺乏足够车辆外观证据。审核文件保留拒绝结论，不把它们变成训练正样本，也不把未检出的整图自动当作已审核负样本。
- 本轮三次真实运行另导出243、81、249张本机照片。数量包括未通过时长验收的20秒尝试；不能称三次完整回合。
- `vision.cmd dataset` 校验审核来源、坐标/图像尺寸、哈希、完整回合隔离及跨集合重复图片；训练/验证都需要已审核的正样本。当前没有这样的正样本集，视觉训练命令已实现，但没有执行微调或制造视觉 best.pt。原有控制模型此前已真实训练。

最终60秒单次视觉前向最大墙钟耗时约0.255秒。三个实例串行调用，整体不是10Hz实时视觉；所有任务时序仍用公开仿真时间。20秒尝试的末尾时间缺口原因没有被定位，不能将重跑成功说成已根治这一现象。入口仍严格要求实际时间线达到请求时长附近；后续长回归必须检查原始JSON。

首次把视觉测试放入默认 tests 时，官方Python没有Torch导致测试失败；已把视觉测试移到 learning/test_vision.py，默认28项重新通过。失败记录保存在 `artifacts/checks/vision-control-first-failed/`，该记录内路径是移动前的原始执行位置。1024模型一致性检查也曾发现连续框边界裁剪差1像素，已修正为W/H边界后重新通过。

## 仍不能声称完成的部分

两个60秒回合均未检出可信车辆，因此像素反馈只通过合成行为测试，未通过真实车辆跟踪验证。没有在线经纬度候选就没有视觉协同目标共享；没有真假识别证据就不上报目标。因此当前成绩为0是本轮功能范围的实际结果，不能用0惩罚或前向成功替代比赛任务完成率。

需要继续用合法图像形成清晰样本，确认相机/采集姿态合同，再实现地理关联和真假辨别，最后验证K=2和600秒完整回合。目前视觉运行依赖工程源码、Torch、视觉权重与控制模块，尚非最终完整视觉单文件提交包。
