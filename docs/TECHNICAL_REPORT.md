# 多无人机视觉搜索、协同定位与固定翼接应

ZqhjGame capture-v31 技术报告，2026-09-13，适用红枫 2026 赛题二。

## 1. 方法与阶段结论

当前发布源码精确对应冻结 v31 的 17 个导出模块。算法从本机 RGB 照片生成轮廓候选，用局部 CNN 判断真假/背景，再通过图像运动和本机位姿估计目标坐标。三机搜索、合法广播、独立视觉确认和解析固定翼运动基元组成协同控制链路；严格坐标上报独立验收。

| seed101，600 仿真秒请求 / 599.9833 秒记录 | 28.33 | 4 | 6.5411588239 米 | 0/3 | 0 |

官方 `passed=false`。分数来自精度维度，捕获与完成时间维度均为 0。这是当前最高单次成绩，尚未建立多 seed 稳定性结论。原始结果直接见 [包内 evaluation](../artifacts/submission/capture-v31/evaluation.json)，无需旧录图即可核查。

## 2. 视觉感知与离线训练

输入为自身公开 RGB 照片，实测 1024×768。灰度自适应阈值与多个固定亮度阈值生成轮廓，按面积、长短边、长宽比、填充率和凸包紧致度筛选。候选面积为 10–1600 像素、长边 8–90 像素、短边至少 2.5 像素；上限 512。每框按长边 1.5 倍截取带上下文的正方形区域，缩放到 64×64。

| 模块 | 结构 |
| --- | --- |
| 卷积特征 | 四层 3×3、步长 2 卷积，通道 16 / 32 / 48 / 64，每层 ReLU |
| 分类头 | Flatten → Linear 1024→64 → ReLU → Linear 64→3 |
| 输出 | 真车、诱饵、背景三类概率；背景不形成车辆输出 |

分类后以 IoU 0.35 去重，最多保留 32 框。导出构造时 detector.confidence 为 0.55，队伍 reset 将候选输出门限设为 0.45；这不是正式身份确认门限。新任务、绑定维持和坐标报告分别应用更严格的条件，不能把较弱原始框当作可靠真车。

部署权重沿用 appearance-v3：35 真车、17 诱饵、709 背景局部样本，每批 48 按三类均衡采样；AdamW，学习率 0.0005、权重衰减 0.005、2400 步。增强包含旋转、缩放、翻转、14–64 像素重采样和亮度扰动。训练直接读取人工审核图片，不调用 UE。

受控留出验证为 34/34 正确，不能外推为正式地图识别率。审核数据和来源图片继续保留，路径迁移见 [资产清单](ARTIFACT_HANDOFF.md#训练数据路径迁移)，训练命令见 [QUICKSTART](QUICKSTART.md)。裁判真值不作为在线输入或自动身份标签。

每机独立模型与单个私有 worker，至少间隔 0.5 仿真秒提交新照片；digest 去重，输出绑定原照片和接收位姿，超过 1 秒的异步结果丢弃。当前为 CPU 推理；模型初始化加载，比赛回调不读模型文件。

## 3. 图像关联、地理定位与身份

背景角点、金字塔光流、前后向检查和 RANSAC 得到单应变换 H，用其预测上一目标在当前图像的位置，再关联候选；无有效 H 时可用相机射线预测像素位置。这能补偿部分相机运动，不能消除树冠、地面和车辆高度造成的视差。

相机光轴由航向加相对 pan 构造。以图像宽 W、水平视场 FOV、主点 (cx, cy) 及前/右/下世界基向量 a、b、c 表示：

```text
f = W / (2 tan(FOV / 2))
ray = a + ((u - cx) / f) b + ((v - cy) / f) c
lambda = (ground_height - aircraft_height) / ray.z
ground_point = aircraft_position + lambda * ray
```

局部地面高度通过两帧静态背景重投影搜索，并用保留特征验证。可用性还受平移基线、相机姿态变化、拟合次数、跨度、年龄与地面高度离散度约束。定位工程预算包括基础项、水平距离、平面离散度及姿态变化，不是标定的概率协方差。照片接收位姿尚未证明等于真实曝光位姿，`capture_verified=False`；单次 RMSE 不能代表全场景精度。

已绑定任务使用本机有限身份记忆：25 米预测匹配、投影面积比 0.35–2.85、匹配间隔不超过 2 秒，最近强真车证据不超过 3 秒。记忆不改写模型类别或概率；三次强诱饵反证跨至少 1 秒撤销，近邻歧义、过期或不匹配会停止延续。重复图片不积分，接应机不能直接继承发现机的身份记忆。

任务中心仅由发现机当前视觉或其合法广播更新。接应视觉需要与独立发现机参考按观测时刻对齐，两者新鲜度不超过 0.8 秒、位置差不超过 25 米，避免接应误关联先污染中心再自证一致。导航预测最多外推 3 秒，不产生新的 visible、定位或报告。

## 4. 搜索、会合与近圈圆弧

三机根据公开区域生成条带并分工搜索；确认目标后发现机召集预计到达较快的空闲队友，另一架继续搜索。通信遵守 50 字节 / 4 Hz；捕获包为 49 个 ASCII 字节、最多 2 Hz。当前同时仅保留一个共享双机任务。

状态为 SEARCH、VERIFY、OFFER、APPROACH、TRACK_PAIR、RECOVER、RELEASE。接应瞄准广播位置之后仍需自身照片独立确认；本地联合计时与引擎真实捕获判定分开。所有有效视觉丢失 8 秒后释放，不能无限凭旧坐标续跟。完整状态合同见 [COOPERATIVE_CAPTURE](COOPERATIVE_CAPTURE.md)。

搜索视场为 50°，活动双机固定 30°，兼顾目标像素与连续几何图像对。世界视线云台按当前自机位姿直接指向任务估计，补偿转弯和平移；初始运动已证但定位尚未确认时保留最多 1.5 秒稳定窗口。云台指向和缩小视场都不构成视觉确认。

接应在 410 米之外保持径向接近，参考速度 32 米/秒；有新鲜发现机广播时引导至目标另一侧的会合位置，没有时使用公开任务点。近圈参考速度 18 米/秒，发现机/接应机期望半径 320 / 360 米；搜索参考 35 米/秒。

### v31 的单项规划改动

活动成员距目标环半径偏差不超过 60 米，且已结束径向接近时，把原四秒直线切向终点改为四秒后的逆时针圆弧终点，并加入匹配 `-degrees(cruise_speed / radius)` 的航向转率候选。以 18 米/秒计算，320 / 360 米环的转率约 −3.223 / −2.865 度/秒。

原转率及速度候选继续保留。规划时域 4 秒、积分步长 0.25 秒，解析评价平滑、安全、临时目标与环绕半径代价；新圆弧候选也通过边界、障碍和队友间距筛选。无可行候选时采取最大预测间距方案并记录不可行，不能据此宣称数学安全保证。

执行接口仍是按首步预测航向构造前方 300 米航点，真实固定翼响应会影响到达、减速和曲率。圆心暂用当前任务点，未加入移动圆心速度前馈。理想运动学一致不等于已稳定盘旋，更不等于相机始终看到目标。

## 5. 严格报告与捕获分开验收

当前坐标上报延续 v22 建立的严格短像素轨迹分支，与导航轨迹确认解耦；旧地理轨迹报告分支关闭。

| 条件 | 当前约束 |
| --- | --- |
| 像素轨迹与身份 | 至少 4 帧关联，至少连续 3 帧强真车；概率 ≥0.95、类别分差 ≥0.9 |
| 一致定位 | 至少 2 次相邻有效估计、间隔不超过 1 秒；相邻水平位移 ≤10+35Δt 米 |
| 运动 | 至少 2 次相对背景运动证据；平面换算速度 3.5–18 米/秒 |
| 姿态与预算 | 快速报告定位时俯角至少 70°，定位工程预算 ≤110 米 |
| 时空绑定 | 当前有效估计、精确照片 digest 一致，接收年龄在 0–0.6 秒 |
| 执行 | 自机 UID / active 状态符合、报告开关开启、共用 1 Hz 限频 |

局部身份记忆不降低新报告门限。引擎要求两机对同一真实目标连续有效跟踪 20 秒，容忍 2 秒短中断才清除；坐标报告并不证明接应已看见同一对象。

## 6. 结果、限制与复现

包内官方评分给出精度维度 94.44、总分 28.33、4 报告、RMSE 6.54115882391099 米。官方目标 10002 / 10003 / 10001 分别有 0 / 21 / 62 个 coop_ticks，后两个各重置一次，最终未捕获。发现机最长有效视觉样本跨度约 10.15 秒，接应未建立独立 own_visual，持续视觉和会合仍是主要限制。

本次发布代码、模型和原始评分保持字节冻结，发布说明和 manifest 元数据更新；当前源码对应 17 模块。包哈希、Git LFS 及数据迁移见 [ARTIFACT_HANDOFF](ARTIFACT_HANDOFF.md)，安装、训练、测试和新回合命令见 [QUICKSTART](QUICKSTART.md)。约 1 GB 的历史原始录图不上传，重新评估不依赖它，但无法只凭 evaluation 重建逐帧回放。

下一步应分开核验早期发现、候选连续性、独立同目标确认和真实飞控响应，用官方首次捕获检验改进，再做多 seed 泛化。当前没有深度地图/ESDF或统一端到端训练图；若恢复 YOPO 学习路线，须另行验证任务梯度到视觉参数、固定翼约束和比赛结果。
