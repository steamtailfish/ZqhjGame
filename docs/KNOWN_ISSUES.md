## 算法问题

| 优先级 / 问题 | 当前证据与影响 | 建议验收 |
| --- | --- | --- |
| P0：接应机独立确认不足 | v31 发现机最长有效视觉样本跨度约 10.15 秒，接应机没有建立独立 own_visual；本地合作与裁判采样采用不同证据 | 分开检查到达、当前候选、身份、运动、定位及同目标关联；必须取得官方真实捕获，不能以瞄准或 APPROACH 代替 |
| P0：双机持续捕获未实现 | 官方目标 10002 / 10003 / 10001 的 coop_ticks 为 0 / 21 / 62，均未清除；后两个有重置 | 两机对同一真实目标连续有效观察 20 秒，短中断容忍 2 秒；零散 tick 不是捕获 |
| P0：候选连续性仍不足 | 当前已加入有限身份记忆，但无框、候选跳变和过期仍会失视；像素运动与世界投影都可能受相机转动、视差和接收时刻影响 | 用准确 source 照片及接收位姿解释中断，不能仅凭近邻或模型预测把被拒框认定为同一真目标，也不能直接放宽置信度或空间门限 |
| P1：近圈引导未证明稳定跟踪 | v31 新增圆弧终点和曲率候选；模型内合理的轨迹仍需经航点飞控执行，接应实际减速和到达时机仍有限制 | 对照真实自机航迹、速度、视觉持续时间、最小间距和官方捕获；不以圆弧模式启用次数替代效果 |
| P1：缺少稳定性证据 | 28.33 是当前最高单次结果；同 seed 也受诱饵与闭环时序影响 | 多 seed 完整回合，汇总报告误差、捕获、惩罚及分数分布 |
| P1：训练数据少且相似 | 35 真车、17 诱饵、709 背景；34/34 留出验证来自有限受控布景 | 扩展人工审核的视角、距离和遮挡，按场景隔离训练与验证；不使用裁判身份自动标注 |
| P1：定位与运动判定未全面标定 | capture_verified=False；局部水平平面、单应变换和接收位姿存在系统误差，110 米是工程预算 | 检查图像时序与地形，分开记录无候选、无运动及定位拒绝，不能把单次 RMSE 当作精度保证 |
| P1：任务点更新依赖发现机 | 接应点不能覆盖独立发现机参考，可避免循环污染，但发现机丢失后尚无可靠接管 | 若研究接管，必须用独立连续视觉证据验证，并保持旧包作对照 |
| P2：尚非论文端到端方案 | 当前局部 CNN + 几何 + 解析规划，无 Nano 或 YOPO 学习评分头 | 另建学习实验验证任务梯度、固定翼约束和官方成绩，不把当前分数归给未启用模块 |

## 运行与交接限制

| 现象 | 处理方法 |
| --- | --- |
| 缺少学习环境 | `vision.cmd` 固定使用 `.venv-learning`；按 [QUICKSTART](QUICKSTART.md) 重建 |
| 找不到 competition / UE | Git 仓库不含官方发行包；采用官方目录内嵌 ZqhjGame 的标准布局 |
| 权重是几行文本或 hash mismatch | 执行 `git lfs pull`，按 [资产清单](ARTIFACT_HANDOFF.md) 校验；不要改哈希绕过 |
| 导出缺 controller | 显式使用 `--controller artifacts/submission/score-v22/agent.py`，保留 v22 依赖 |
| 隔离检查缺固定照片 | 完成 Git LFS 下载；该受控测试照片属于 v22 依赖 |
| 训练找不到原机图片 | JSONL 的 image 含历史绝对路径；生成本机 accepted-local.jsonl 并核验图片哈希，不能只复制 JSONL |
| 包运行却不报告 | 必须带 `--enable-reports`；然后检查候选与报告条件，不能只看进程是否正常 |
| 修改 src 后行为不变 | submission 使用冻结副本，必须导出新包并核查 runner-call.json |
| 6379 占用或输出目录已存在 | 同时只运行一场比赛，每场用新目录；不要全局结束 Python/Redis 或覆盖旧证据 |
| `--device cuda` 没改变正式包 | 当前 submission 自建 CPU 检测器，不透传这个参数；硬件迁移需另导出验证 |
| 降低 max-photos 后仍有图片 | 它仅限制稀疏导出，不控制 UE 渲染或推理频率；外围关键帧记录另有预算 |
| GitHub 找不到 v31 原 run / 回放图片 | 约 1 GB 原始录图仅本地保留；包内 evaluation 足以查分，重跑会生成自己的完整记录 |
| 旧报告写 v22 / v26 | 冻结历史文件保留当时事实；当前命令与方法以 README、QUICKSTART 和技术报告为准 |
